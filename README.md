# Global Energy Market Research & Analytics

## Overview

A data analytics project focused on exploring global energy production, consumption and renewable-energy trends using Python, SQL Server and Power BI.

## Objectives

- Analyse global energy production and consumption trends
- Compare energy indicators across major countries
- Examine oil, gas and coal production
- Analyse renewable electricity generation
- Perform SQL-based data analysis
- Build an interactive Power BI dashboard

## Tools & Technologies

- Python
- Pandas
- SQL Server
- Power BI
- Power Query
- Excel/CSV
- Data Visualization
- Statistical Analysis

## Dataset

The project uses the **Our World in Data Energy Dataset**, which provides country-level and year-level information on energy production, consumption and electricity generation.

Source: Our World in Data Energy Data
